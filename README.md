# ⚖️ سامانه جامع هوشمند آموزش و سنجش وکالت چتر دانش (حق‌یار)
### Chatre Danesh & HaqYar — AI Law Education, Bar Exam Analytics & Dual Messenger Bots (Telegram & Bale)

پلتفرم پیشرفته و یکپارچه آموزش، سنجش، برنامه‌ریزی و شبیه‌سازی آزمون‌های حقوقی ایران (وکالت کانون وکلای دادگستری اسکودا، مرکز وکلای قوه قضائیه، آزمون تصدی منصب قضاوت و سردفتری اسناد رسمی) مجهز به موتور هوش مصنوعی RAG، کارگاه آزمون شفاهی اختبار و ربات‌های تعاملی بله و تلگرام.

---

## 🌟 ویژگی‌ها و ماژول‌های کلیدی

### ۱. پرتال داوطلب و کارنامه تحلیلی ۶ درس
- **محاسبه‌گر تراز قانون تسهیل صدور مجوزهای کسب‌وکار:** ارزیابی قبولی قطعی بر مبنای کسب ۷۰٪ میانگین تراز ۱٪ برتر کشور (۶۰٪ برای سهمیه ایثارگران).
- **کارنامه تفکیکی ۶ درس وکالت:** حقوق مدنی (ضریب ۳)، آیین دادرسی مدنی (ضریب ۳)، حقوق تجارت (ضریب ۲)، حقوق جزا (ضریب ۲)، آیین دادرسی کیفری (ضریب ۲) و اصول فقه و متون فقه (ضریب ۱).
- **داشبورد کایزن و عارضه‌یابی نوسان تمرکز:** سنجش شاخص‌های شتاب‌زدگی، تردید گزینه‌ای و فرسودگی ذهنی.

### ۲. کارگاه آزمون شفاهی و اختبار وکالت با هوش مصنوعی (AI Oral Examiner)
- ضبط صدای داوطلب با قابلیت تبدیل صوت به متن (Speech-to-Text).
- تطبیق خودکار استدلال با مواد قانون مدنی (مانند ماده ۸۰۳)، دادرسی مدنی (ماده ۱۰۷) و مجازات اسلامی (ماده ۶۷۴).
- نمره‌دهی از ۰ تا ۲۰ همراه با سنجش سلاست کلام و تشخیص اصطلاحات دکترین.

### ۳. اطلس تله‌های تستی مواد قانونی (Test Traps Atlas)
- دسته‌بندی تله‌های پرتکرار آزمون‌های سنوات گذشته به صورت نمودار درختی (Tree Map).
- تحلیل تله‌های خطرناک: خیار شرط بدون مدت (ماده ۴۰۱ ق.م)، مالکیت مافی‌الذمه در تعدد وراث (ماده ۳۰۰ ق.م)، استرداد دادخواست و صلاحیت دادگاه‌های صلح جدید مصوب ۱۴۰۲.

### ۴. موتور بازیابی معنایی و تگ‌گذاری خودکار در Hugging Face (RAG & Auto-Tagging)
- پایگاه دانش استاندارد تست‌های وکالت در پوشه `huggingface-static/`.
- نوت‌بوک آموزش، فاین‌تیون و ارزیابی در Google Colab با قابلیت لاگ در Weights & Biases (W&B).
- استخراج شماره مواد قانون، آراء وحدت رویه و قوانین خاص با سرعت بالا.

### ۵. موتور دوگانه ربات‌های پیام‌رسان بله و تلگرام (Dual-Engine Bots)
- **پشتیبانی هم‌زمان از بله (`tapi.bale.ai`) و تلگرام (`api.telegram.org`)** در سرورلس کلودفلر (`lib/api-router.ts`).
- **تست روزانه وکالت:** ارسال خودکار سوال با دکمه‌های شیشه‌ای و تصحیح آنی با ذکر مستند ماده قانونی.
- **ورود ۱-کلیکی (SSO):** توکن امن یک‌بارمصرف برای ورود بدون رمز از بله و تلگرام به میزکار وب.
- **کرون‌جاب خودکار کانال‌ها:** ارسال تست و نکته تحلیلی روزانه با `channel-worker/worker.js`.

### ۶. باشگاه رتبه‌های برتر، معرف‌ها و تسویه شبا (CRM & Payouts)
- سیستم اختصاصی معرفی و ثبت‌نام با کدهای تخفیف رتبه‌های تک‌رقمی.
- محاسبه خودکار پورسانت و تسویه حساب با ثبت شماره شبا بانکی.

## 🚀 راهنمای نصب و راه‌اندازی محلی

### پیش‌نیازها:
- Node.js نسخه 18 یا بالاتر
- کلید API برای هوش مصنوعی (Google Gemini یا Cloudflare Workers AI)

```bash
# ۱. نصب پکیج‌ها
npm install

# ۲. کپی متغیرهای محیطی
cp .env.example .env

# ۳. اجرای سرور توسعه
npm run dev
```

---

## ☁️ استقرار روی Cloudflare (Pages / Workers / D1)

```bash
# ۱. اعمال اسکیمای دیتابیس D1
npx wrangler d1 execute chatre-danesh-db --remote --file=./schema.sql

# ۲. استقرار ربات و توابع API
npx wrangler deploy

# ۳. استقرار کرون‌جاب ارسال به کانال‌ها
cd channel-worker
npx wrangler deploy
```

## 📂 ساختار دایرکتوری‌ها

```
├── src/                    # فرانت‌اند اصلی React 19 + TypeScript
│   ├── components/         # کامپوننت‌های کارنامه، آزمون شفاهی، تله‌ها و CRM
│   ├── lib/                # توابع تله‌ها، پروفایل‌ها، ثبت لاگ و دیتابیس
│   ├── types.ts            # تایپ‌های اختصاصی آزمون‌های وکالت
│   └── constants.ts        # تنظیمات برند چتر دانش و موسسات همکار
├── lib/                    # روتر سرورلس بک‌اند (api-router.ts)
├── channel-worker/         # کرون‌جاب پست روزانه در بله و تلگرام
├── huggingface-static/     # اسپیس استاتیک Hugging Face RAG و دیتابیس تست‌ها
├── schema.sql              # ساختار کامل دیتابیس Cloudflare D1
└── wrangler.json           # تنظیمات استقرار کلودفلر
```
