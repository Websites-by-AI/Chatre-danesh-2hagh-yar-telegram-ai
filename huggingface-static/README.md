# ⚖️ موتور هوشمند RAG و تگ‌گذاری سوالات وکالت چتر دانش (حق‌یار)

این یک **Hugging Face Space استاتیک هوشمند** برای بازیابی معنایی، شناسایی سال آزمون، درس، ماده قانونی و تله‌های تستی آزمون‌های وکالت (اسکودا و مرکز وکلا)، قضاوت و سردفتری است.

## ✨ ویژگی‌ها
- 🔍 **جستجوی هوشمند اصطلاحات فقهی و حقوقی** با نرمالایزر فارسی
- 🏷️ **تگ‌گذاری خودکار (Auto-Tagging):** استخراج شماره ماده قانون، درس و رأی وحدت رویه
- ⚖️ **پوشش آزمون‌های وکالت، قضاوت و سردفتری**
- 🤖 **ارزیابی دقت و اتصال به Weights & Biases (W&B)**
- ⚡ **سازگار با ربات‌های بله، تلگرام و وب‌سایت اصلی چتر دانش**
